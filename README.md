# 微光原 · Shimmer Meadow

> Vercel 在线版：https://quick-olive-qfob7lc.vercel.app/
>
> GitHub Pages 备份：https://yi260602.github.io/shimmer-meadow/

一个单文件的 Three.js 黄昏云海场景：风、飞鸟般的轻光、黑色脸庞的白色小人、会跟着你的第二个小人，以及散落在草地里的七根蜡烛。

## 打开

双击 `index.html` 即可，无需构建工具或本地服务器。

Three.js 通过 CDN 加载（内置备用源），首次打开需要联网；若资源加载失败，页面会显示提示。

## 操作

- `WASD` / 方向键：行走；起飞后控制飞行方向
- 按住 `空格`：上升；松开：缓缓下落
- 鼠标左键或右键拖动：环顾
- `Q` / `E`：左右转视角
- 滚轮：拉近 / 拉远
- 触屏：左侧摇杆行走/控向，右侧长按飞升，拖动画面环顾

## 场景

- 黄昏天空从暖橙、淡紫过渡到深蓝，缓慢循环
- 起伏的草甸、云海、柔光和薄雾
- 靠近烛火自动点亮，光点会飞向小人；没有计数、没有失败、没有倒计时
- 飞得越高，小人身上的柔光越强，身后拖出一条淡淡的光带
- 圆形柔性边界，不会掉出世界
- 飞进云团时画面会短暂被柔光遮挡
